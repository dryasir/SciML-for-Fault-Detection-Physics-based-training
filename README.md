# Scientific machine learning for seismic fault and discontinuity detection: physics-based training versus conventional deep learning

# What is this repository for?
Supervised convolutional neural networks (CNNs) are a standard tool for seismic fault interpretation, but depend on manually interpreted labels that are scarce, incomplete, and subjective. We present a scientific machine learning (SciML) approach in which a U-Net learns Faults/discontinuity from physics-based synthetic seismic data: layered impedance models are folded, faulted, and convolved with wavelets matched to the measured spectrum of the target survey, so every training sample carries an exact label, including examples without faults. The network is trained with a class-weighted cross-entropy and Dice loss, masked where labels are unknown, and Monte-Carlo dropout provides predictive uncertainty. We compare the developed method with a conventional CNN trained on five hand-interpreted inlines, as in our earlier study. Because the F3 block (Dutch North Sea) has no complete fault interpretation, both methods are first scored on a benchmark survey with exact ground truth that carries the statistical F3 wavelet and F3-coloured noise. On 18 held-out inlines, SciML fine-tuned on the same five inlines improves F1 from 0.850 to 0.881, IoU from 0.739 to 0.787, and average precision from 0.924 to 0.952, and reduces false alarms by 32% (95% bootstrap interval of the F1 gain: +0.027 to +0.035). Without any survey labels, SciML reaches 97% of the conventional F1 while producing 36% fewer false alarms. On real F3 data, 19.5% of the conventional detections run parallel to reflectors, a signature of false picks on strong horizons, compared with 2.7% for SciML.

It extends our earlier 2D CNN workflow (`CNN-fault-prediction.ipynb`) with a **scientific machine learning (SciML)** workflow. In it, a U-Net learns **Faults/discontinuity** from physics-based synthetic seismic data with exact labels. It is compared quantitatively with the conventional, label-driven workflow.

## Key results

Both methods were scored on 18 held-out inlines of a benchmark survey with exact ground truth. The benchmark carries the F3 statistical wavelet and F3-coloured noise.

| Method | Precision | Recall | F1 | IoU | MCC | AP |
|---|---|---|---|---|---|---|
| Conventional ML (original workflow) | 0.828 | 0.873 | 0.850 | 0.739 | 0.840 | 0.924 |
| SciML, no labels | 0.871 | 0.780 | 0.823 | 0.699 | 0.814 | 0.904 |
| **SciML + fine-tune (same 5 inlines)** | **0.878** | **0.884** | **0.881** | **0.787** | **0.873** | **0.952** |

- With the same labelled inlines, SciML has **32% fewer false alarms** and **8% fewer missed faults**. The 95% bootstrap interval of the F1 gain is **+0.027 to +0.035**, and SciML is better on 18 of 18 test inlines.
- With **no labels at all**, SciML reaches 97% of the conventional F1 and has 36% fewer false alarms.
- On real F3 data (inline 462), **19.5%** of the conventional detections run parallel to reflectors (a sign of false picks on strong horizons). For SciML the figure is **2.7%**.
- A model that never predicts a fault already scores an accuracy of **0.94**, so accuracy alone is misleading for fault detection.

## Data

The F3 Netherlands seismic data are publicly available from dGB Earth Sciences through the [TerraNubis portal](https://terranubis.com).

- File used: `Seismic_F03-002.sgy`: 853,776 traces, 645 samples at 4 ms, inlines 99–824, crosslines 125–1300, 25 m bins.
- **Header bytes:** inline = 21, crossline = 25 (not the SEG-Y rev1 standard 189/193); UTM coordinates in bytes 73/77.
- Dominant frequency about 42 Hz (−6 dB band 5–66 Hz).

The benchmark survey and all synthetic training data are generated by the notebook from fixed random seeds, so they are fully reproducible.

## Method summary

- **Conventional ML (baseline):** hand-interpreted inlines → global min–max scaling → 64 × 64 fault-only patches → U-Net with binary cross-entropy → tiled prediction with threshold 0.5.
- **Scientific ML:**
  - Physics-based forward model `s = w ∗ R′(m) + η`: layered earth, folding, faulting with exact labels, a wavelet matched to the F3 spectrum, and noise.
  - Fault **and** no-fault training samples, with local-RMS amplitude conditioning.
  - U-Net with batch-norm and Monte-Carlo dropout, trained with a class-weighted cross-entropy + soft Dice loss (masked for unknown labels).
  - Optional fine-tuning on interpreted inlines, including 3D sparse-slice supervision.
  - Gaussian-blended sliding-window prediction with uncertainty (σ).
- **Evaluation:**
  - Benchmark survey with exact ground truth: confusion matrices, F1, IoU, MCC, AP, bootstrap confidence intervals.
  - Real F3: a label-free physical criterion, the angle between detections and reflectors measured with the structure tensor.
